1. Core Function
This program allows the user to set reminders and stay focused while doing tasks.

2. Human Context
When you have a busy schedule for example you would set things to do/ reminders and timers that help tell you to do some paper work for one job.

3. Intended User
This is meant for every day Joe, but it is most helpful for people that need help focusing/ remembering what to do like a student.

4. Behavioral Thesis
This tool is heavily focused on behavior change. For example it sets timers for tasks but gives you more time to do a task if you need it. It also goes from time attentive to fun in a matter of seconds. 

5. Dignity Clause
It gives you time for breaks and it allows you to add more time on a timer if you need it. These changes allow you to feel less shame and stress about the timer. Rather than it being a strict thing that's watching your every move it's just a guide. This app also doesn't have any features that would cause a decrease in dignity.

6. Refusal Clause
It won't intentionally become just like the regular Iphone reminders app because that is really bland.

7. Atmospheric Tone
It should feel like a very animated guide that allows you to have fun while getting your work done on time.

I want this system to have the meaning of helping you get done with tasks will being engaging. I will make sure to not invade privacy like taking photos/ mining data, I will also refrain from making a black background with blue UI because thats very templety, finally I will not make my extension force for your attention rather I want it to be more of a you want to get your stuff done.
